Part 01

Approach: set the system once, then assemble.

The site's whole look comes from a small set of rules applied with discipline: two typefaces, a warm neutral palette with one brown accent, 2px corners on anything clickable, hairline dividers, and generous vertical rhythm. If those rules live in Elementor's Site Settings before a single page is built, every widget inherits them and the pages come together fast.

The vibe in one sentence: quiet, editorial, warm. Small uppercase labels with wide tracking, big unhurried Tenor Sans headlines, stone-grey body copy, and lots of air. Nothing bounces, glows, or uses a drop shadow bigger than a whisper. When in doubt, remove something.

Install the stack

WordPress + Elementor Pro (needed for Theme Builder header/footer, the Form widget, the Gallery widget with filters, and Popups). Use a blank theme (Hello Elementor). Turn on Flexbox Container and Nested Elements in Elementor → Settings → Features.

Site Settings → Global Colors & Fonts

Enter the palette from Part 02 and the four font roles from Part 03. Disable Elementor's default colours and typography (Settings → General) so nothing inherits the theme's blue.

Site Settings → Layout, Buttons, Form Fields

Content width 1240, section padding, button and field defaults from Parts 04–05. Paste the Custom CSS from Part 08 into Site Settings → Custom CSS.

Theme Builder → Header and Footer

Build once from Part 06, set display conditions to Entire Site.

Build the reusable sections as Saved Templates

Stats strip, Suite card, Package grid, Detail card, Enquiry band, "Come see the space" CTA. Save each as a template so Home, Packages and Contact reuse the same object.

Assemble the five pages

Follow the blueprints in Part 07 top to bottom. Every section is a container with the padding from Part 04; alternate white and linen backgrounds exactly as listed.

Forms, WhatsApp, SEO, launch

Part 09: wire the enquiry forms to email, add the WhatsApp launcher, set redirects for the old URLs, upload OG image and favicons, install an SEO plugin and add the LocalBusiness schema.

Radii and lines

  • 2px — buttons, badges, chips, filter buttons, image captions. Anything clickable and small is almost square.
  • 6px — form inputs, feedback panels, code blocks.
  • 8px — detail cards, gallery tiles, glance cards.
  • 10px — suite cards, package grid outer edge, values grid, partner strip, hire strip, story image. 12px only on the contact form card.
  • Hairlines — the site draws 0.5px lines in Divider (#E0DDD8). Elementor's minimum is 1px; 1px in the same colour reads fine. On dark surfaces use white at 8–15% opacity.
  • Shadows — header on scroll: 0 2px 24px rgba(0,0,0,.06). Suite card hover: 0 16px 48px rgba(0,0,0,.08) with 4px lift. Detail card hover: 0 4px 24px rgba(0,0,0,.05). Nothing else has a shadow.

Motion

  • Scroll reveal — most blocks fade up 22px over 0.7s when they enter the viewport. In Elementor: Advanced → Motion Effects → Entrance Animation: Fade In Up, Duration: Slow. Stagger siblings with delays of 0 / 80 / 160 / 240ms (the site's d1–d4 classes).
  • Hero entrance — eyebrow, headline and sub/buttons rise in sequence at 100 / 250 / 400ms. Same Fade In Up with those delays.
  • Hover — colour changes over 200–220ms; suite card lifts 4px over 300ms; story image scales 1.04 over 600ms. Set Hover Animation to none and use Transition Duration in the widget's hover tab instead.
  • Nothing else moves. No bounce, no parallax, no zoom-in entrances.

Floating WhatsApp launcher

56px circle, #25D366, fixed bottom-right 24px, z-index 300, shadow 0 4px 20px rgba(37,211,102,.35), a slow 2.5s pulse ring, scales 1.1 on hover. On the live site it opens a bottom-sheet form (name, phone, event type, guests, date, suite, package, message) that composes a WhatsApp message to +27 76 182 3532. Custom CSS

Paste into Site Settings → Custom CSS (Elementor Pro). It covers the few things the UI can't set: the scroll shadow on the header, the thin hamburger, the en-dash list bullets, the ghost word on the partner strip, the WhatsApp pulse, and the hairline focus ring. Add the named classes via Advanced → CSS Classes on the matching element.

  --oa-linen:#F5F2EE; --oa-divider:#E0DDD8;
}
html{ scroll-behavior:smooth; }
body{ -webkit-font-smoothing:antialiased; }

  background:var(--oa-charcoal); box-shadow:0 -6px 0 var(--oa-charcoal),0 6px 0 var(--oa-charcoal); }

/* Nav pointer as a 1px hairline that grows from the left */

Part 09

Plugins, forms & SEO

The Astro site is static and ships zero tracking by default. Keep the WordPress build equally lean: every plugin below has a reason.

Plugins

  • Elementor + Elementor Pro — Theme Builder, Form, Gallery, Popup, Custom CSS.
  • Hello Elementor theme — blank canvas, no theme CSS to fight.
  • Rank Math or Yoast — titles, descriptions, OG image, sitemap, LocalBusiness schema.
  • Redirection — keep the trailing-slash URLs (/about/, /packages/, /gallery/, /contact/) 1:1; the old site's sitemap is already indexed.
  • Image optimisation (ShortPixel, Imagify or similar) — or upload the WebPs from the repo directly and skip it.
  • Click to Chat (optional) — if you'd rather not build the WhatsApp popup by hand.
  • Cookie notice — only needed if you add analytics. The live site shows a notice only when GA is on.

Forms

  • Three forms: enquiry band (Home, 4 fields), full enquiry (Contact, 9 fields), WhatsApp sheet (composes a wa.me message, sends nothing to a server).
  • Elementor Pro Form → Actions After Submit: Email to info@venueoaon.co.za, subject "New Enquiry: Venue Oaón". Add a honeypot field (the site uses one named botcheck).
  • Alternative: keep Web3Forms. Set the form's action to https://api.web3forms.com/submit with a hidden access_key; the key in the repo's src/config.ts is public by design and domain-allowlisted, so add the new domain in the Web3Forms dashboard.
  • Install an SMTP plugin (WP Mail SMTP) so form emails actually arrive.

SEO & assets to carry over

  • og-image.jpg (1200×630), favicons (16, 32, 180 apple-touch), site.webmanifest, theme-colour #8B6448.
  • Page titles and descriptions are in each src/pages/*.astro frontmatter; copy them verbatim.
  • JSON-LD from index.astro (LocalBusiness + EventVenue with geo −25.663333, 28.259444, opening hours, suites as offers) and about.astro (Organization). Paste into the SEO plugin's custom schema or an HTML widget in the head.
  • Language en-ZA, hreflang en-ZA + x-default, canonical per page, legal pages noindex.

Pre-launch checklist

  • Global colours and fonts entered; Elementor default colours/fonts disabled.
  • Tenor Sans is never bold; Inter never above 500.
  • Every section alternates white / linen exactly as blueprinted; the dark ladder (Charcoal strip → Espresso band → #121212 footer) is intact.
  • All buttons 48px tall, 2px radius, uppercase 10px letter-spaced.
  • Header fixed at 100 / 80 / 68px and every page's first section clears it.
  • Entrance animations are Fade In Up only, staggered, and off under reduced motion.
  • Forms send an email and show the success panel; WhatsApp launcher opens with +27 76 182 3532 prefilled.
  • Gallery filters work and the lightbox opens; images are WebP.
  • Titles, descriptions, OG image, favicons, schema, redirects, sitemap submitted.
  • Mobile pass at 390px: hero panel, 2×2 stats, stacked columns, full-width buttons.
